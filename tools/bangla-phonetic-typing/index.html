Capital letters matter: T Th D Dh N S R Rh Ng NG O I U. A consonant followed by a consonant joins automatically (kt = ক্ত, bidyut = বিদ্যুত). To avoid the join, type o or ` between them (koto = কত).

How to use the bangla phonetic typing

  1. Type in the top box using English letters, for example ami banglay gan gai.
  2. Read the Bangla in the second box as you type.
  3. Use capital letters for the retroflex and special sounds (T, D, N, S, O and so on). The key chart shows every letter.
  4. Press Copy Bangla text and paste it into Facebook, WhatsApp, Word or a form.

Frequently asked questions

How do I type Bangla with English letters?

Write the words the way they sound. For example ami becomes আমি and bangladesh becomes বাংলাদেশ. Consonants that follow each other join automatically, so dhonyobad becomes ধন্যবাদ.

How do I type the ো vowel sign?

Use a capital O after a consonant. tOmake becomes তোমাকে. A small o after a consonant adds no vowel sign, which is the inherent অ sound.

How do I stop two letters from joining?

Type o or the backtick between them. koto is কত, while kto is the joined ক্ত.

Is this the same as Avro Keyboard?

It follows the same Avro-style idea and most of the same keys, but it is a separate tool. A few rare combinations may differ, so check the key chart.

Does it work on my phone?

Yes. Type in the English box with your normal keyboard, then copy the Bangla text. It does not need any app or font download, because modern phones show Bangla.

Is my text uploaded?

No. The conversion runs in your browser.
